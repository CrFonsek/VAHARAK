# VAHRAK

Prototipo de una interfaz web para la gestión y el seguimiento de entregas de SODIMAC. Incluye vistas de supervisor, conductor y cliente.

## Abrir el proyecto

El archivo principal es [`index.html`](./index.html). Puedes abrirlo en un navegador para explorar la interfaz. La página carga Tailwind CSS, Google Fonts y Font Awesome desde Internet, por lo que algunas partes visuales requieren conexión.

## Vistas incluidas

- **Supervisor:** resumen de la operación y gestión de flota.
- **Conductor:** ruta y acciones rápidas.
- **Cliente:** seguimiento del pedido y ubicación del vehículo.

## Estado

Este repositorio contiene un prototipo de interfaz estática. No requiere instalar dependencias ni ejecutar un proceso de compilación.

> El repositorio es privado; para abrir sus archivos desde otro dispositivo, inicia sesión en GitHub con una cuenta que tenga acceso.
